# 第三方头图版权声明（assets/banners）

本目录**不存放任何图片文件**，只保留这份声明。插件中心里的第三方游戏封面（反恐精英 2、战争雷霆等）是各自权利人的美术作品，不随本仓库分发。

## 分发方式

| 项 | 说明 |
| --- | --- |
| 图片托管位置 | [DG-LAB-Client-Plugin](https://github.com/CrimsonSeraph/DG-LAB-Client-Plugin) 仓库的 `banners/` 目录 |
| 引用方式 | 插件侧车 `plugin.json` 的 `banner` 字段写绝对 https URL，宿主直接把该 URL 当 `Image.source` 加载，不复制也不再分发图片本体 |
| 仓库内残留 | 无。`module/**/meta/` 下不再有封面图，构建产物同样不含第三方图片 |

## 版权归属

- 图片版权归其原权利人（游戏开发商与发行商）所有，本项目不对其主张任何权利
- 图片仅用于标识对应游戏的插件条目，属描述性使用，不代表原权利人的认可或授权
- 图片**不适用**本仓库的 GPL-3.0-only 许可：复制、分发或商用前请自行向权利人取得授权

## 新增封面

封面图请提交到 DG-LAB-Client-Plugin 仓库的 `banners/`，再在本仓库侧车 `plugin.json` 里写 URL。不要提交进本仓库：`banner` 只接受纯文件名（宿主按插件目录读取）与绝对 http(s) URL（宿主直接联网加载），相对路径、`file://` 等写法按无图处理。
