# DG-LAB-Client 更新摘要

本文件面向普通用户，只列出可感知的新增、改进、修复和重要说明。完整技术变更、内部重构、构建与测试调整见 [CHANGELOG.md](CHANGELOG.md)。

> 说明：摘要按用户可感知价值分类，不逐条对应 CHANGELOG 的 Added / Changed。内部构建、测试、文档发布流程调整不进入本摘要。

## Unreleased

### 改进

- **三平台安装包视觉统一**：Windows 安装向导支持自定义侧边栏背景、安装/卸载图标和默认桌面快捷方式；macOS DMG 增加背景图与窗口布局；Linux 增加标准桌面入口和多尺寸图标。

### 说明

- **AppImage 资源复用**：AppImage 打包复用统一桌面文件与图标资源，属于打包内部整理，安装包内容与使用方式不变。

## v2.5.0 - 2026-10-31

### 新增

- **多设备连接与设备管理**：支持同时连接多台输出设备；新增「设备管理」页，集中管理扫描连接、已连接链路、默认设备、通道上限与安全上限、通道级回退值。
- **迷你窗与托盘常驻**：可查看 A/B 强度与占比、启停通道、调整透明度与大小、查看最近触发和滚动波形；关闭主窗口后隐藏到托盘。
- **插件中心增强**：支持搜索、分类过滤、网格/列表切换和已启用栏；插件可展示中文名、作者、描述、标签、头图和事件声明；插件详情增加「数值」页签和规则入口。
- **事件引擎与插件规则图**：事件可按强度、百分比或波形输出，支持同通道互斥和触发流水；插件级规则图可从总图进入并跳回。
- **波形库与标签库**：内置官方 16 个只读波形，支持单条与 zip 批量导入导出；新增波形标签库和按目标通道清除波形；波形行可展开静态波形图。
- **插件内容扩充**：新增战争雷霆遥测插件；CS2 插件数值与事件扩充。
- **可配置文件日志**：日志按天写入并按大小滚动，日志独立成页，支持按级别过滤、刷新和导出。
- **网卡 IP 选择**：可手动指定有效 IPv4 并按黑白名单过滤，选择结果随配置持久化。
- **设备型号识别与默认设备**：扫描结果区分已支持 / 实验性 / 驱动未实现；默认设备在可输出设备间按郊狼优先评选，并可在首页下拉覆盖。
- **实验性设备接入**：负鼠振动控制器（输出）与爪印无线按钮、灵猫气压传感器（输入）以实验性方式接入；爪印与灵猫支持多台独立实例。
- **图标与连接状态**：左侧导航改用图标；连接状态统一为「已连接设备 ×N + 蓝牙 + App」，并按真实链路数计数。

### 改进

- **规则图按设备输出**：每个通道节点可选目标设备，目标设备离线时不下发并记录日志；同一设备同一通道只保留一条连线。
- **规则编辑器跨图暂存**：总图与插件图改动留在内存，保存时一次写入所有有改动的图；编辑器改为可缩放独立窗口，关闭时有改动会确认。
- **首页三行布局**：设备状态、插件与近期触发、A/B 通道与各自波形卡分行显示，窄窗口下更易读。
- **配置文件外部修改即时生效**：手动编辑配置后自动重载；保存时与磁盘做三方合并，减少覆盖外部新增键。
- **主题与取色调整**：默认主题改为 `classic`；自定义主题选色改为应用内对话框，支持 HEX 与色相/饱和度/明度滑杆。
- **自动更新链路补全**：检查、下载、SHA256 校验、脚本安装与重启链路补全，可跳转发布页查看完整说明。
- **页面与入口精简**：主窗口改为窄列表导航；配置页只保留连接与主题；模块页并入插件中心；软件更新收进独立对话框；强度调节移到迷你窗。
- **蓝牙操作集中到设备管理页**：扫描、连接、断开、强度与电量操作从设置页搬到设备管理页，设置页只保留中转连接与主题。
- **插件详情精简**：通道上限与安全上限迁到设备管理页的「通道级回退值」；插件详情保留「触发事件」「数值」两个页签。

### 修复

- **退出与蓝牙稳定性**：修复退出崩溃、蓝牙强度不回显、电量读取异常、重连后未重发上次强度等问题。
- **规则命令通道解析**：修复规则命令通道解析错误，避免 B 通道强度落到 A 通道。
- **界面与日志细节**：修复配对二维码载荷、日志级别过滤、界面回显细节和规则编辑器右键菜单等问题。

### 重要说明

- **实验性设备验证状态**：负鼠、爪印、灵猫仍属实验性接入；未实机验证项见 [待实机验证清单](docs/devices.md#待实机验证清单)。
- **功能迁移与移除**：移除模块页、示例插件和内置默认规则；相关功能迁移到插件中心、插件规则图和社区插件模板。

## v2.0.0 - 2026-09-22

### 新增

- **QML 界面层**：新增左侧导航、页面栈、状态栏与原生标题栏。
- **主题令牌系统**：提供 16 套预设主题和自定义主/副色，并按 WCAG 校正对比度。
- **首页与配置页卡片**：新增首页 A/B 通道面板、配置页连接/主题/日志卡片、应用信息与设备控制桥接对象。
- **波形库与编辑器**：支持选择波形、编辑段落与关键帧、实时预览和发送。
- **应用内 WebSocket 中转**：应用直接托管 V3/V4 中转服务，不再依赖 Node 官方后端与 Python 桥接。
- **内置二维码**：配对二维码由应用自身生成。
- **可视化规则编辑器**：支持规则、模块源、运算符、高级和通道输出节点，支持拖拽连线、右键建节点和复制粘贴。
- **郊狼 V3 蓝牙直连**：支持扫描、连接、定时写入强度与波形、读取强度和电量。
- **主题化输入控件**：界面统一使用 `App*` 封装控件。

### 改进

- **程序入口与界面栈**：程序入口改为 `QGuiApplication` + `QQmlApplicationEngine`，界面统一使用 Basic 控件样式。
- **依赖调整**：新增 Qt WebSockets / Bluetooth 依赖，移除 Qt Widgets 依赖。
- **Windows 运行时部署**：Windows 构建后自动部署 Qt 运行时。
- **主题文档补充**：主题令牌、预设色值与扩展方式补充到主题文档。

### 修复

- **QML 加载与单例**：修复 QML 主界面加载失败与设计令牌单例失效。
- **浅色主题文字可见性**：修复浅色主题下次要文字几乎不可见。
- **输入控件主题跟随**：修复原生输入控件未跟随主题。
- **规则编辑器主题化**：修复规则编辑器画布、节点、端口、连线和检查器未使用主题令牌。

### 重要说明

- **界面大版本重构**：旧 Qt Widgets 界面、旧规则编辑 UI、旧对话框、Python WebSocket 通信层和 `qcss` 主题样式表已移除。
- **Python 依赖变化**：不再需要 Python `websockets` / `qrcode` 依赖；保留 `python/PathFinder.py` 供 GSI 插件使用。

- **日志与规则编辑**：修复日志清理分组、规则值模式编辑未应用、Python 日志换行与导入缺失。
